# 50代からの毎日コーデ

無理しない。高すぎない。ちゃんと素敵。

1アイテム税込1万円以下を目安にした、50代女性向けの100コーデを紹介する日本語の静的サイトです。写真はAIで生成した架空の人物・衣服です。価格は参考レンジであり、実在商品の販売価格ではありません。

## 表示・操作

- 768px以下は縦1列、769pxから2列、1024pxから3列、1280pxから4列。
- 季節・服の種類・テイスト・用途のフィルターを1つ選んで絞り込み。
- カードを選ぶと詳細モーダル。前へ・次へは絞り込み結果内で移動。写真の左右スワイプも利用できます。
- Escapeキー・右上の閉じるボタンで閉じられます。
- フィルターチップ以外に横スクロールはありません。

## ローカルで確認

ビルドやパッケージのインストールは不要です。Node.jsがある場合は、リポジトリのルートで `node scripts/serve.cjs` を実行し、表示されたローカルURLを開いてください。

## 画像の追加方法・ファイル名

`assets/images/` に `outfit-001.webp` から `outfit-100.webp` を配置します。3桁のゼロ埋め番号を使います。追加時は `outfit-101.webp` のように続けてください。

縦横比は4:5、推奨サイズは960×1200px。頭から靴まで全身が入る画像にしてください。圧縮時にも顔・服の質感が読み取れる品質を保ちます。画像が未配置または読込に失敗した場合は4:5のプレースホルダーが表示されます。

写真の生成条件：架空の日本人または東アジア系50代女性、自然な年齢表現・体型、自然光、清潔感、ロゴなし、高級ブランド表現なし。1品税込1万円以下で再現できそうな服装にします。モデル、髪型、体型、背景、ポーズ、色、靴、バッグが偏らないようにします。

## コーデデータの追加方法

`data/outfits.js` の `window.OUTFITS` 配列に1件追加してください。HTMLにカードを追加する必要はありません。

必須フィールド：`id`（一意の整数）、`image`（相対パス）、`title`、`season`（配列）、`category`（配列）、`tops`、`bottoms`、`shoes`、`colors`（配列）、`price`、`point`、`priceItems`。

`priceItems` は `{ label: 'トップス', min: 1990, max: 5990 }` の形式です。重ね着を同一価格レンジで表す場合は `quantity: 2` を追加します。合計価格には数量を反映してください。`outer` と `bag` は任意です。表示する品目は内訳に含め、各品目の価格上限を税込1万円以下とします。ワンピースはトップス欄に服装、ボトムス欄に「ワンピース一体型」を記載します。

季節は春・夏・秋・冬、カテゴリは服の種類、テイスト、用途を含めてください。フィルターの名称と一致した項目が絞り込まれます。実在ブランドの商品画像や実在人物の肖像を使用しないでください。

`scripts/build-data.cjs` は初期100件の編集用ソースです。`node scripts/build-data.cjs` を再実行すると `data/outfits.js` を上書きするため、直接編集後は実行しないでください。

## GitHub Pagesで公開

1. GitHubの `orbitcraf` アカウントに公開リポジトリ `50s-fashion-lookbook` を作成します。
2. このフォルダのサイトファイル、データ、100枚の画像、`.nojekyll` を `main` ブランチにpushします。
3. リポジトリの Settings → Pages → Build and deployment で「Deploy from a branch」を選びます。
4. ブランチを `main`、フォルダを `/ (root)` にして保存します。
5. Pagesのデプロイ成功後、公開URLで画像・フィルター・スマホの縦1列表示を確認します。

公開先： https://orbitcraf.github.io/50s-fashion-lookbook/

アセットは相対パスを使用しています。GitHub Pagesのサブディレクトリで動作し、`.nojekyll` でJekyll処理を無効化します。

## 確認

既存画像の圧縮は `node scripts/optimize-images.cjs` で実行できます。実行前の100枚を `backups/images-日時/` に保存し、SHA-256でバックアップを検証してから、寸法とファイル名を保ってWebPを再圧縮します。容量が増える画像は元のまま保持します。バックアップと容量比較レポートはローカルに残し、GitHub Pagesにはアップロードしません。復元する場合はバックアップ内のWebPを `assets/images/` にコピーしてください。繰り返し圧縮は避け、再調整にはバックアップの元画像を使用してください。

`node scripts/check.cjs` でデータ数、配分、価格、画像名、画像の存在を確認できます。画像配置前のレイアウト確認は `node scripts/check.cjs --allow-missing-images` を使います。

ブラウザでは320・375・390・768・769・1024・1280pxの幅で列数と横方向のはみ出しを確認してください。画像が100枚読み込めること、全フィルター、モーダルの閉じる・前へ・次へ・スワイプ・キーボード操作も確認します。

自動ブラウザ検証は `npm install`、`npx playwright install chromium` を実行後、ローカルサーバーを起動して `npm test` を実行します。未配置画像を許容する場合は `node scripts/browser-check.cjs --allow-missing-images`。公開版の検証は環境変数 `LOOKBOOK_URL` に公開URLを指定します。既存ブラウザを使う場合は `LOOKBOOK_BROWSER` にその実行ファイルのパスを指定できます。

`node scripts/image-check.cjs` は画像100枚の寸法・形式・重複を確認し、`tmp/` に目視確認用のコンタクトシートを作成します。画像変換・検証に使うSharpとPlaywrightは開発用依存関係です。公開サイトにはNode.jsも外部ライブラリも不要です。
